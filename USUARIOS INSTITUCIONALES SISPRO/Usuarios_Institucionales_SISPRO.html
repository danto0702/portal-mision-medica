Pasos para activar el backend
  1. Abre la hoja de arriba → menú Extensiones → Apps Script.
  2. Borra el contenido y pega el código del archivo Apps_Script_Backend.gs (está en esta misma carpeta).
  3. Guarda (💾). Luego Implementar → Nueva implementación → Aplicación web.
  4. En "Ejecutar como": Yo. En "Quién tiene acceso": Cualquier usuario.
  5. Copia la URL /exec y pégala arriba. (Opcional) define el mismo token que en el script.
  6. Usa Probar conexión para verificar.
